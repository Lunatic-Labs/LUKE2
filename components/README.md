# Reusable design system / UI primitives

Nothing here knows about a specific scene.

- `BottomBar.tsx` — the carousel navigation bar (ported from `BottomBar.pde`).
- `CampusBackdrop.tsx` — tinted campus photo and skyline behind the attract
  screen and main menu.
- `SceneFrame.tsx` — layout wrapper giving a scene its drawing area.
- `ScenePlaceholder.tsx` — stand-in panel for a scene that is registered but
  not yet built.
